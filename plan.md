# Gun Violence Interactive Heatmap – Technical Plan

## 1. Overview

Build a **single-page web application** that displays an interactive choropleth (heatmap) of the United States showing **firearm mortality rates** by state. Users can:

1. See **raw rates** colored on a map.
2. Toggle **confounder checkboxes** (income, education, poverty, race composition, heavy drinking, depression, etc.) to see **adjusted (residual)** rates.
3. View **top 10 / bottom 10** states in both raw and adjusted views.
4. See how much variance each confounder explains **individually** (simple R²) and **marginally** when combined with others (ΔR² or partial R²).
5. Compare **predicted vs. actual** rates to identify "over-performing" and "under-performing" states relative to their socio-economic profile.

## 3. Statistical Methodology

### 3.1 Outcome Variable (Y)

Primary: `mortality_firearm_age_adj_12mo_ending_2023Q1`

(Optionally allow user to switch to homicide or overdose.)

### 3.2 Predictor Variables (X)

Each checkbox corresponds to one predictor:

| Checkbox Label | Variable |
|----------------|----------|
| Median Income | `income_median_household_2022` (log-transform recommended) |
| Poverty Rate | `poverty_rate_2022_pct` |
| Education (Bachelor's+) | `education_bachelors_or_higher_2022_pct` |
| Unemployment | `unemployment_rate_2022_pct` |
| % White | `pct_white` |
| % Black | `pct_black` |
| % Asian | `pct_asian` |
| Heavy Drinking | `heavy_drinking_prevalence_2022_crude` |
| Depression | `depression_prevalence_2022_crude` |

### 3.3 Metrics to Display

For **each predictor i**:

1. **Individual R²ᵢ** – variance explained when that predictor alone is regressed on Y.
   ```
   R²ᵢ = 1 − SSE(Yᵢ) / SST(Y)
   ```

2. **Marginal ΔR²ᵢ** – additional variance explained when predictor i is added to the currently selected set S:
   ```
   ΔR²ᵢ = R²(S ∪ {i}) − R²(S)
   ```
   (Show this only when other predictors are selected.)

### 3.4 Adjusted Values & Residuals

When a set S of predictors is selected:

1. Fit OLS: `Y ~ X_S` (using all selected predictors).
2. Compute predicted values `Ŷ` and residuals `e = Y − Ŷ`.
3. **Adjusted rate** for display = residual `e` (centered, or shifted to mean Y for interpretability).
4. **Predicted vs Actual** view: color states by residual sign/magnitude:
   - **Red/orange**: actual >> predicted (worse than expected)
   - **Green/teal**: actual << predicted (better than expected)

### 3.5 Sorting Checkboxes by Effect

On page load (or when no predictors are selected), sort checkboxes **descending by individual R²**.

When some predictors are already selected, optionally re-sort by **marginal ΔR²** so the user sees which remaining predictor would add the most explanatory power.

## 7. Regression Implementation (Pseudocode)

```javascript
// Simple OLS for multiple predictors
function ols(X, y) {
  // X: n×p matrix, y: n×1 vector
  // β = (XᵀX)⁻¹ Xᵀy
  const Xt = transpose(X);
  const XtX = matmul(Xt, X);
  const XtX_inv = invert(XtX);
  const Xty = matmul(Xt, y);
  const beta = matmul(XtX_inv, Xty);
  
  const yHat = matmul(X, beta);
  const residuals = subtract(y, yHat);
  
  const ssRes = sumOfSquares(residuals);
  const ssTot = sumOfSquares(subtract(y, mean(y)));
  const rSquared = 1 - ssRes / ssTot;
  
  return { beta, yHat, residuals, rSquared };
}

// Individual R² for predictor i
function individualR2(xi, y) {
  const X = addIntercept(xi); // [[1, xi0], [1, xi1], ...]
  return ols(X, y).rSquared;
}

// Marginal ΔR² when adding predictor i to set S
function marginalR2(S, i, allX, y) {
  const rS = selectedR2(S, allX, y);
  const rSi = selectedR2([...S, i], allX, y);
  return rSi - rS;
}
```

For a robust implementation, use **simple-statistics** or **ml-matrix** to handle matrix inversion safely (add small regularization if needed for collinear predictors).

## 9. Example User Flow

1. **Page loads**: Map shows raw firearm rates. Checkboxes sorted by R². Top checkbox is "% Black" (R² ≈ 0.52 hypothetically).

2. **User checks "% Black"**: 
   - Map switches to Adjusted view automatically (or user selects).
   - Colors now show residuals: states with high violence *after* accounting for % Black are red.
   - Marginal ΔR² updates for remaining predictors.
   - "Combined R²" panel shows 0.52.

3. **User checks "Poverty Rate"**:
   - Combined R² jumps to ~0.60.
   - Residuals recalculated.
   - Mississippi might shift from "worst" to "middle" if its high rate is explained by poverty + race.

4. **User clicks "Predicted vs Actual"**:
   - Green states: doing better than their demographics would predict.
   - Red states: doing worse.
   - Tables update to show "most over-performing" and "most under-performing".
